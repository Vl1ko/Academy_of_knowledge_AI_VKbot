# Изменение логики приоритета ИИ над менеджером

## Цель
Максимизировать общение ИИ с клиентом и переводить на менеджера только в крайних случаях.

## Основные принципы
1. **ИИ должен отвечать на все информационные вопросы**
2. **Менеджер нужен только для:**
   - Записи на экскурсию/консультацию
   - Прямых запросов на администратора
   - Сложных проблем, которые ИИ не может решить

## Изменения в логике обработки

### 1. Изменен порядок проверок в `process_message`
**Старый порядок:**
1. Проверка запроса на экскурсию
2. Проверка вопроса о доступности мест
3. Проверка запроса на консультацию
4. Проверка прощания
5. Обработка через ИИ

**Новый порядок:**
1. Проверка прощания (ИИ)
2. Проверка вопроса о доступности мест (ИИ)
3. Проверка подтверждения записи на экскурсию
4. **Проверка запроса на экскурсию (менеджер)**
5. **Проверка запроса на консультацию (менеджер)**
6. Обработка через ИИ

### 2. Упрощен метод `_is_admin_help_request`
**Удалены слишком общие фразы:**
- "помощь", "вопрос", "не знаю", "не понимаю"
- "уточнить", "подробнее", "больше информации"
- "консультация", "встреча", "визит"

**Оставлены только прямые запросы:**
- "оператор", "администратор", "менеджер"
- "записаться", "регистрация", "хочу прийти"
- "позвоните", "звонок", "связаться"
- "есть проблема", "не получается"

### 3. Улучшены ответы ИИ при неуверенности
**При неуверенном ответе:**
- Сначала предлагает переформулировать вопрос
- Не сразу переводит на менеджера

**При отсутствии ответа:**
- Предлагает переформулировать вопрос
- Упоминает возможность связаться с менеджером для сложных вопросов

## Когда ИИ отвечает
- Информационные вопросы: "Хочу узнать про школу"
- Общие вопросы: "Расскажите о программах"
- Справочные запросы: "Какие есть занятия", "Сколько стоит"
- Прощания и благодарности
- Вопросы о доступности мест

## Когда переводится на менеджера
- **Запросы на экскурсию** (после подтверждения)
- **Прямые запросы на администратора**: "оператор", "менеджер"
- **Запросы на запись**: "записаться", "хочу прийти"
- **Запросы на звонок**: "позвоните", "звонок"
- **Конкретные проблемы**: "есть проблема", "не получается"

## Результат
- ИИ максимально общается с клиентом
- Менеджер привлекается только при необходимости
- Улучшен пользовательский опыт
- Снижена нагрузка на менеджеров
