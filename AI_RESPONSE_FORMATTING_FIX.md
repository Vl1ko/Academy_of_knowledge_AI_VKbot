# Исправление форматирования ответов ИИ

## Проблемы
1. ИИ каждый раз писал "Здравствуйте!" в начале ответа
2. Ответы содержали markdown форматирование, которое не поддерживается ВК

## Решения

### 1. Убрано приветствие "Здравствуйте!" из системного промпта
**Файл:** `src/ai/gigachat_handler.py`

**Изменение:**
- Удалено "Здравствуйте!" из примера структурированного ответа в системном промпте
- Теперь ИИ не будет автоматически добавлять приветствия в ответы

### 2. Убрано markdown форматирование
**Файл:** `src/bot/structured_response.py`

**Изменения в методе `format_response`:**
- Удалено сложное форматирование абзацев
- Добавлена фильтрация приветствий из ответов
- Добавлено удаление markdown тегов:
  - `**жирный**` → `жирный`
  - `*курсив*` → `курсив`
  - `` `код` `` → `код`
  - `# Заголовок` → `Заголовок`
  - `[текст](ссылка)` → `текст`

### 3. Упрощено форматирование ответов
**Старая логика:**
- Сложное разделение на абзацы
- Форматирование цен
- Добавление уточняющих вопросов
- Добавление информации о времени для звонка

**Новая логика:**
- Простое удаление приветствий
- Удаление markdown форматирования
- Сохранение основного содержания ответа

## Результат
- ИИ больше не пишет "Здравствуйте!" в каждом ответе
- Ответы не содержат markdown форматирования
- Текст отображается корректно в ВК
- Сохраняется основное содержание ответов

## Примеры изменений

**Было:**
```
Здравствуйте!

**Стоимость обучения** в 1 классе составляет *26100 рублей* в месяц.

В стоимость включено:
• Время пребывания в школе
• Расширенная программа обучения

Укажите удобное время для звонка в будний день с 10:00 до 17:00
```

**Стало:**
```
Стоимость обучения в 1 классе составляет 26100 рублей в месяц.

В стоимость включено:
• Время пребывания в школе
• Расширенная программа обучения
```

## Файлы изменены
- `src/ai/gigachat_handler.py` - убрано приветствие из системного промпта
- `src/bot/structured_response.py` - упрощено форматирование ответов
