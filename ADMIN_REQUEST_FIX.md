# Исправление логики перевода на администратора

## Проблема
Бот неправильно переводил на администратора при информационных запросах типа "Хочу узнать про школу", хотя должен был отвечать через ИИ.

## Причина
В методе `_is_admin_help_request` была слишком широкая логика, которая срабатывала на любые запросы, содержащие слова "вопрос", "помощь" и другие общие фразы.

## Решение
Улучшена логика определения запросов на администратора:

### 1. Удалены слишком общие фразы
- Убрано слово "вопрос" из списка фраз для перевода на администратора
- Оставлены только специфичные запросы на помощь

### 2. Добавлена проверка информационных запросов
Добавлен список фраз, которые НЕ должны переводить на администратора:
- "хочу узнать", "расскажите", "что такое"
- "информация о", "про школу", "про детский сад"
- "какие есть", "сколько стоит", "какие программы"

### 3. Новая логика работы
1. Сначала проверяется, содержит ли сообщение запросы на администратора
2. Если да, то дополнительно проверяется, не является ли это информационным запросом
3. Если это информационный запрос - НЕ переводим на администратора
4. Если это реальный запрос на помощь - переводим на администратора

## Когда переводится на администратора
- Прямые запросы: "оператор", "администратор", "менеджер"
- Запросы на запись: "записаться", "регистрация"
- Запросы на встречу: "встреча", "приехать", "прийти"
- Запросы на звонок: "позвоните", "звонок"
- Проблемы: "не могу", "не получается", "есть проблема"
- Консультации: "нужна консультация", "проконсультироваться"

## Когда НЕ переводится на администратора
- Информационные запросы: "хочу узнать про школу"
- Общие вопросы: "расскажите о программах"
- Справочные запросы: "какие есть занятия", "сколько стоит"

## Результат
Теперь бот правильно обрабатывает информационные запросы через ИИ, а на администратора переводит только при реальной необходимости.
