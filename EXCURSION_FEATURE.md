# Функциональность экскурсии и вызова администратора

## Описание изменений

Добавлена расширенная функциональность для обработки запросов на экскурсию, консультацию и других случаев, когда пользователь хочет связаться с администратором. Теперь все подобные запросы сразу переводят на администратора без сбора дополнительной информации.

## Основные изменения

### 1. Обработка запросов на экскурсию

**Файл:** `src/bot/message_handler.py`

- Добавлен метод `_is_excursion_request()` для определения запросов на экскурсию
- Добавлен метод `_handle_excursion_request()` для обработки запросов на экскурсию
- Добавлен метод `_notify_admins_about_excursion_request()` для уведомления администраторов

### 2. Обработка запросов на консультацию

**Файл:** `src/bot/message_handler.py`

- Обновлен метод `_is_consultation_request()` для определения запросов на консультацию
- Изменена логика: теперь консультации сразу переводят на администратора вместо заполнения формы

### 3. Расширенная логика вызова администратора

**Файл:** `src/bot/message_handler.py`

- Расширен метод `_is_admin_help_request()` для включения большего количества случаев
- Обновлен метод `_handle_admin_help_request()` для универсальной обработки
- Обновлены методы уведомления администраторов для единообразия

### 4. Кнопка завершения диалога

**Файл:** `src/bot/keyboard_generator.py`

- Добавлен метод `generate_finish_dialog_keyboard()` для создания красной кнопки "Завершить диалог с менеджером"

### 5. Обработка payload кнопок

**Файл:** `src/bot/message_handler.py`

- Добавлена обработка payload в метод `process_message()`
- Добавлена логика для команды `finish_dialog`

## Логика работы

### Запрос на экскурсию

1. Пользователь отправляет сообщение с запросом на экскурсию
2. Бот определяет запрос как экскурсию по ключевым словам
3. Бот отключает ИИ для данного пользователя
4. Бот отправляет сообщение: "Отлично, сейчас уточняем возможные дни и время для экскурсии. В ближайшее время дадим ответ"
5. Бот показывает красную кнопку "Завершить диалог с менеджером"
6. Администраторы получают уведомление о запросе экскурсии

### Запрос на консультацию

1. Пользователь отправляет сообщение с запросом на консультацию
2. Бот определяет запрос как консультацию по ключевым словам
3. Бот отключает ИИ для данного пользователя
4. Бот отправляет сообщение: "Я перевожу Вас на администратора. Пожалуйста, подождите немного."
5. Бот показывает красную кнопку "Завершить диалог с менеджером"
6. Администраторы получают уведомление с текстом сообщения пользователя

### Вызов администратора (расширенная логика)

1. Пользователь отправляет сообщение, которое определяется как запрос на помощь администратора
2. Бот отключает ИИ для данного пользователя
3. Бот отправляет сообщение: "Я перевожу Вас на администратора. Пожалуйста, подождите немного."
4. Бот показывает красную кнопку "Завершить диалог с менеджером"
5. Администраторы получают уведомление: "Пользователь {ID} вызывает администратора. Сообщение: {текст сообщения}"

### Завершение диалога

1. Пользователь нажимает кнопку "Завершить диалог с менеджером"
2. Бот включает ИИ обратно для данного пользователя
3. Бот отправляет сообщение: "Диалог с менеджером завершен. Я снова на связи! Чем могу помочь?"
4. Бот показывает основное меню

## Использование

После внедрения изменений:

1. При запросе экскурсии бот автоматически переведет пользователя на администратора
2. При запросе консультации бот также переведет на администратора
3. При любом запросе на помощь, запись или уточнение бот переведет на администратора
4. Пользователь увидит красную кнопку "Завершить диалог с менеджером"
5. Администраторы получат уведомление с текстом сообщения пользователя
6. После завершения диалога пользователь сможет продолжить общение с ботом
