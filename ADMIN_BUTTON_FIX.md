# Исправление кнопки "Связаться с администратором"

## Проблема
При нажатии на кнопку "Связаться с администратором" бот запускал форму с запросом времени для звонка вместо того, чтобы сразу переводить пользователя на администратора.

## Решение
Изменена логика обработки кнопки "Связаться с администратором":

### 1. Изменения в `src/bot/keyboard_generator.py`
- Добавлен payload `{"command": "admin_help"}` для кнопки "Связаться с администратором"
- Теперь кнопка отправляет команду вместо обычного текста

### 2. Изменения в `src/bot/message_handler.py`
- Добавлена обработка команды `admin_help` в метод `_handle_command`
- При получении команды `admin_help`:
  - Отключается ИИ для пользователя
  - Отправляется уведомление администраторам
  - Пользователь получает сообщение о переводе на администратора
  - Показывается кнопка "Завершить диалог с менеджером"

## Результат
Теперь при нажатии на кнопку "Связаться с администратором":
1. Пользователь сразу переводится на администратора
2. Администраторы получают уведомление с именем пользователя
3. Не запускается форма с запросом времени

## Файлы изменены
- `src/bot/keyboard_generator.py` - добавлен payload для кнопки
- `src/bot/message_handler.py` - добавлена обработка команды admin_help
