# Административные команды бота

## Обзор

Бот поддерживает административные команды для управления правами администраторов прямо в чате. Эти команды доступны только пользователям с правами администратора.

## Доступные команды

### 1. `/add <VK_ID>` - Добавить администратора

Добавляет пользователя с указанным VK ID в список администраторов.

**Синтаксис:**
```
/add <VK_ID>
```

**Примеры:**
```
/add 123456789
/add 987654321
```

**Функциональность:**
- Проверяет права администратора у отправителя команды
- Получает имя пользователя из VK API
- Создает новую запись в базе данных или обновляет существующую
- Устанавливает флаг `is_admin = True`
- Логирует действие в системе

**Ответы:**
- ✅ Успех: `"✅ Создан новый администратор Иван Петров (ID: 123456789)"`
- ❌ Ошибка: `"VK ID должен быть числом. Используйте: /add <VK_ID>"`

### 2. `/del <VK_ID>` - Удалить администратора

Удаляет права администратора у пользователя с указанным VK ID.

**Синтаксис:**
```
/del <VK_ID>
```

**Примеры:**
```
/del 123456789
/del 987654321
```

**Функциональность:**
- Проверяет права администратора у отправителя команды
- Запрещает удаление прав у самого себя
- Проверяет существование пользователя в базе данных
- Проверяет, является ли пользователь администратором
- Устанавливает флаг `is_admin = False`
- Логирует действие в системе

**Ответы:**
- ✅ Успех: `"✅ Права администратора удалены у пользователя Иван Петров"`
- ❌ Ошибка: `"❌ Вы не можете удалить права администратора у самого себя."`

## Требования безопасности

### Права доступа
- Команды доступны только администраторам
- Неавторизованные пользователи получают сообщение: `"У вас нет прав для выполнения административных команд."`

### Защита от самоудаления
- Администратор не может удалить права у самого себя
- Это предотвращает случайную потерю доступа к административным функциям

### Валидация данных
- VK ID должен быть положительным числом
- Проверяется корректность формата команды
- Обрабатываются ошибки VK API

## Обработка ошибок

### Типичные ошибки и их решения:

1. **"VK ID должен быть числом"**
   - **Причина:** Неверный формат VK ID
   - **Решение:** Убедитесь, что VK ID является числом

2. **"VK ID должен быть положительным числом"**
   - **Причина:** Отрицательный или нулевой VK ID
   - **Решение:** Используйте положительное число

3. **"Пользователь с ID X не найден в базе данных"**
   - **Причина:** Пользователь не существует в системе
   - **Решение:** Сначала добавьте пользователя через `/add`

4. **"Пользователь X не является администратором"**
   - **Причина:** Пользователь уже не является администратором
   - **Решение:** Команда не нужна, пользователь уже не администратор

5. **"Вы не можете удалить права администратора у самого себя"**
   - **Причина:** Попытка самоудаления
   - **Решение:** Попросите другого администратора удалить ваши права

## Логирование

### Все административные действия логируются:

- **Добавление администратора:**
  ```
  INFO: Admin 123456789 added admin 987654321 (Иван Петров)
  ```

- **Удаление администратора:**
  ```
  INFO: Admin 123456789 removed admin rights from 987654321 (Анна Сидорова)
  ```

### Логи содержат:
- ID администратора, выполнившего действие
- ID целевого пользователя
- Имя целевого пользователя
- Тип действия (добавление/удаление)

## Интеграция с VK API

### Получение имен пользователей:
- Команды автоматически получают имена пользователей из VK API
- Если имя недоступно, используется "Неизвестный пользователь"
- Ошибки VK API не блокируют выполнение команд

### Обработка ошибок API:
- Сетевые ошибки
- Неверный токен
- Недоступность API
- Закрытые профили

## Советы по использованию

### Рекомендации:
1. **Проверяйте VK ID** перед выполнением команд
2. **Используйте команды осторожно** - изменения необратимы
3. **Ведите учет** добавленных/удаленных администраторов
4. **Проверяйте логи** для аудита действий

### Лучшие практики:
1. Добавляйте только доверенных пользователей
2. Регулярно проверяйте список администраторов
3. Удаляйте права у неактивных администраторов
4. Используйте команды только при необходимости
