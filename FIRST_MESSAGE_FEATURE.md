# Обработка первого сообщения с номером телефона

## Описание функциональности

Данная функциональность автоматически обрабатывает первое сообщение от клиента, содержащее номер телефона, и генерирует стандартизированный ответ согласно требованиям. После получения времени от пользователя система отправляет подтверждение и уведомляет администраторов.

## Логика работы

### 1. Определение первого сообщения с номером телефона

Система считает сообщение первым с номером телефона, если:
- В сообщении присутствует номер телефона в одном из поддерживаемых форматов
- История диалога с пользователем пуста или содержит только текущее сообщение

### 2. Поддерживаемые форматы номеров телефонов

- `+7 (XXX) XXX XX XX` - стандартный формат с кодом страны
- `8 (XXX) XXX XX XX` - формат с восьмеркой
- `+7XXXXXXXXXX` - сплошной формат с кодом страны
- `8XXXXXXXXXX` - сплошной формат с восьмеркой
- `XXX XXX XX XX` - формат без кода страны

### 3. Извлечение имени пользователя

Система автоматически извлекает имя из сообщения по следующим правилам:
- Ищет слова, начинающиеся с заглавной буквы
- Исключает служебные слова (привет, здравствуйте, добрый и т.д.)
- Возвращает максимум 2 слова (имя и фамилия)
- Если имя не найдено, использует "Клиент"

### 4. Генерация первого ответа

Стандартный ответ имеет формат:
```
Здравствуйте, {ИМЯ}! Укажите удобное время для звонка с 10.00 до 18.00 в любой будний день. Менеджер обязательно с Вами свяжется.
```

### 5. Обработка времени от пользователя

После получения первого ответа система ожидает указания времени от пользователя. Поддерживаемые форматы времени:

- `10:00`, `9:30` - стандартный формат с двоеточием
- `10.00`, `9.30` - формат с точкой
- `10 00`, `9 30` - формат с пробелом
- `10ч`, `10ч 30м` - сокращенный формат
- `10`, `15` - простое число (преобразуется в 10:00, 15:00)

### 6. Генерация ответа на время

После получения времени система генерирует ответ:
```
Благодарим за заявку, менеджер свяжется с Вами в {ВРЕМЯ}
```

### 7. Уведомление администраторов

При получении времени система автоматически отправляет уведомление всем администраторам:
```
Пользователь {user_id} оставил номер телефона {номер_телефона} и просит связаться с ним в {время}
```

## Техническая реализация

### Добавленные методы в MessageHandler

#### `_extract_phone_number(message: str) -> Optional[str]`
Извлекает номер телефона из сообщения с помощью регулярных выражений.

#### `_extract_name(message: str) -> Optional[str]`
Извлекает имя пользователя из сообщения с помощью эвристического анализа.

#### `_is_first_message_with_phone(user_id: int, message_text: str) -> bool`
Определяет, является ли сообщение первым с номером телефона.

#### `_handle_first_message_with_phone(user_id: int, message_text: str) -> Dict[str, Any]`
Обрабатывает первое сообщение с номером телефона и генерирует ответ.

#### `_is_time_response_after_phone(user_id: int, message_text: str) -> bool`
Определяет, является ли сообщение указанием времени после первого сообщения с телефоном.

#### `_is_time_format(message: str) -> bool`
Проверяет, содержит ли сообщение формат времени.

#### `_extract_time_from_message(message: str) -> str`
Извлекает и форматирует время из сообщения.

#### `_handle_time_response_after_phone(user_id: int, message_text: str) -> Dict[str, Any]`
Обрабатывает указание времени и генерирует ответ.

#### `_notify_admins_about_phone_time_request(user_id: int, phone: str, time: str) -> None`
Отправляет уведомление администраторам о запросе на звонок.

### Добавленные методы в DatabaseHandler

#### `update_user_phone(vk_id: int, phone: str) -> bool`
Обновляет номер телефона пользователя в базе данных.

## Примеры использования

### Пример 1: Полный диалог с именем и телефоном
**Сообщение 1:** `Иван Петров +7 (999) 123 45 67`
**Ответ бота:** `Здравствуйте, Иван Петров! Укажите удобное время для звонка с 10.00 до 18.00 в любой будний день. Менеджер обязательно с Вами свяжется.`

**Сообщение 2:** `10:00`
**Ответ бота:** `Благодарим за заявку, менеджер свяжется с Вами в 10:00`

**Уведомление администраторам:** `Пользователь 123456789 оставил номер телефона +79991234567 и просит связаться с ним в 10:00`

### Пример 2: Диалог только с телефоном
**Сообщение 1:** `+7 (999) 123 45 67`
**Ответ бота:** `Здравствуйте, Клиент! Укажите удобное время для звонка с 10.00 до 18.00 в любой будний день. Менеджер обязательно с Вами свяжется.`

**Сообщение 2:** `15`
**Ответ бота:** `Благодарим за заявку, менеджер свяжется с Вами в 15:00`

### Пример 3: Сообщение без телефона
**Сообщение:** `Привет, как дела?`
**Результат:** Обычная обработка через AI (функциональность не активируется)

## Интеграция в существующий код

Функциональность интегрирована в метод `process_message` класса `MessageHandler` и выполняется в следующем порядке:

```python
# Проверяем первое сообщение с номером телефона
if self._is_first_message_with_phone(user_id, message_text):
    return self._handle_first_message_with_phone(user_id, message_text)

# Проверяем, указал ли пользователь время после первого сообщения с телефоном
if self._is_time_response_after_phone(user_id, message_text):
    return self._handle_time_response_after_phone(user_id, message_text)
```

## Сохранение данных

При обработке первого сообщения с номером телефона система:
1. Сохраняет или обновляет данные пользователя в базе данных
2. Добавляет сообщение бота в историю диалога
3. Логирует успешный ответ

При обработке времени система:
1. Извлекает и форматирует время
2. Генерирует ответ пользователю
3. Отправляет уведомление администраторам
4. Добавляет сообщение бота в историю диалога
5. Логирует успешный ответ

## Тестирование

Функциональность протестирована с помощью автоматизированных тестов, которые проверяют:
- Извлечение номеров телефонов в различных форматах
- Извлечение имен из сообщений
- Определение форматов времени
- Извлечение и форматирование времени
- Генерацию корректных ответов
- Интеграционную работу всех компонентов

## Ограничения

1. Алгоритм извлечения имени основан на эвристике и может не работать корректно в сложных случаях
2. Поддерживаются только российские номера телефонов
3. Функциональность активируется только для первого сообщения пользователя
4. Некоторые сложные форматы времени (например, "10 часов") могут не распознаваться корректно
