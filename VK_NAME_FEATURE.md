# Получение имен пользователей из VK API

## Обзор изменений

Добавлена функциональность автоматического получения имен пользователей из VK API вместо использования "Клиент" по умолчанию.

## Изменения в коде

### 1. Добавленные импорты в `src/bot/message_handler.py`

```python
import vk_api
from vk_api.exceptions import VkApiError
from config.config import VK_TOKEN
```

### 2. Новый метод `_get_vk_user_name()`

```python
def _get_vk_user_name(self, user_id: int) -> Optional[str]:
    """
    Get user name from VK API
    
    Args:
        user_id: VK user ID
        
    Returns:
        User name or None if not found
    """
```

**Функциональность:**
- Получает информацию о пользователе через VK API
- Извлекает имя и фамилию
- Возвращает полное имя в формате "Имя Фамилия"
- Обрабатывает ошибки API и возвращает None при неудаче

### 3. Обновленный метод `_handle_first_message_with_phone()`

**Изменения:**
- Добавлена проверка имени из VK API, если имя не найдено в сообщении
- Приоритет: сообщение → VK API → "Клиент"

```python
# Если имя не найдено в сообщении, пытаемся получить из VK API
if not name:
    name = self._get_vk_user_name(user_id)

# Если имя все еще не найдено, используем "Клиент"
if not name:
    name = "Клиент"
```

### 4. Обновленный метод `_notify_admins_about_phone_time_request()`

**Изменения:**
- Добавлено получение имени пользователя для уведомлений администраторов
- Улучшенный формат уведомления с именем пользователя

```python
# Получаем имя пользователя из VK API
user_name = self._get_vk_user_name(user_id)
if user_name:
    notification = f"Пользователь {user_name} (ID: {user_id}) оставил номер телефона {phone} и просит связаться с ним в {time}"
else:
    notification = f"Пользователь {user_id} оставил номер телефона {phone} и просит связаться с ним в {time}"
```

## Примеры работы

### Пример 1: Пользователь с именем в сообщении
**Сообщение:** `Иван Петров +7 (999) 123 45 67`
**Результат:** `Здравствуйте, Иван Петров! Укажите удобное время для звонка...`

### Пример 2: Пользователь без имени в сообщении
**Сообщение:** `+7 (999) 123 45 67`
**VK API:** Возвращает "Анна Сидорова"
**Результат:** `Здравствуйте, Анна Сидорова! Укажите удобное время для звонка...`

### Пример 3: Пользователь с закрытым профилем
**Сообщение:** `+7 (999) 123 45 67`
**VK API:** Не может получить информацию
**Результат:** `Здравствуйте, Клиент! Укажите удобное время для звонка...`

## Обработка ошибок

### Типы ошибок:
1. **VkApiError** - ошибки VK API (неверный токен, недоступность API)
2. **Exception** - общие ошибки (сетевые проблемы, проблемы с токеном)

### Логирование:
- Все ошибки логируются с уровнем ERROR
- Включается информация о пользователе и типе ошибки
- Система продолжает работать даже при ошибках API

## Требования

### Зависимости:
- `vk_api` - библиотека для работы с VK API
- `VK_TOKEN` - токен доступа к VK API

### Права доступа:
- Токен должен иметь права на чтение информации о пользователях
- Минимальные права: `users.get`

## Безопасность

### Защита данных:
- Имена пользователей получаются только при необходимости
- Ошибки API не влияют на основную функциональность
- Токен VK API хранится в переменных окружения

### Ограничения:
- API имеет лимиты на количество запросов
- Информация доступна только для публичных профилей
- Некоторые пользователи могут скрывать свои данные

## Производительность

### Оптимизация:
- Запросы к VK API выполняются только при необходимости
- Результаты не кэшируются (каждый раз свежие данные)
- Ошибки API не замедляют основной функционал

### Мониторинг:
- Все запросы к API логируются
- Время выполнения запросов отслеживается
- Ошибки API анализируются для улучшения
