# Управление администраторами бота

## Обзор

В системе администраторы хранятся в таблице `users` с полем `is_admin=True`. Администраторы получают уведомления о новых заявках от клиентов и имеют доступ к административным функциям.

## Способы добавления администраторов

### 1. Интерактивный скрипт (рекомендуется)

Запустите скрипт `add_admin.py` для интерактивного управления администраторами:

```bash
python3 add_admin.py
```

Этот скрипт предоставляет меню с возможностями:
- Добавить администратора
- Удалить права администратора
- Показать список администраторов
- Добавить администратора с автоматическим получением имени из VK API

### 2. Быстрое добавление

Для быстрого добавления одного администратора используйте `quick_add_admin.py`:

```bash
python3 quick_add_admin.py <VK_ID>
```

Пример:
```bash
python3 quick_add_admin.py 123456789
```

### 3. Через переменные окружения

Администраторы также могут быть указаны в файле `.env`:

```env
ADMIN_IDS=123456789,987654321,555666777
```

## Структура базы данных

### Таблица `users`

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | Integer | Первичный ключ |
| `vk_id` | Integer | VK ID пользователя (уникальный) |
| `name` | String | Имя пользователя |
| `phone` | String | Номер телефона |
| `is_admin` | Boolean | Статус администратора (True/False) |
| `last_activity` | DateTime | Время последней активности |
| `last_message` | Text | Последнее сообщение |
| `child_age` | Integer | Возраст ребенка |
| `created_at` | DateTime | Дата создания записи |

## Функции администраторов

### 1. Получение уведомлений

Администраторы автоматически получают уведомления о:
- Новых заявках на консультацию
- Запросах на экскурсию
- Первых сообщениях с номерами телефонов

### 2. Административные команды

Администраторы могут использовать команды, начинающиеся с `/`:
- `/stats` - статистика бота
- `/users` - список пользователей
- `/notifications` - непрочитанные уведомления

### 3. Управление диалогами

Администраторы могут:
- Переключать пользователей на себя
- Завершать диалоги с менеджерами
- Просматривать историю сообщений

## Получение VK ID

### Способ 1: Через профиль пользователя
1. Откройте профиль пользователя в ВКонтакте
2. В URL будет виден ID: `https://vk.com/id123456789`
3. Скопируйте число после `id`

### Способ 2: Через настройки профиля
1. Войдите в свой аккаунт ВКонтакте
2. Перейдите в настройки профиля
3. В разделе "Основная информация" найдите "ID страницы"

### Способ 3: Через API (для разработчиков)
```python
import vk_api
vk_session = vk_api.VkApi(token='YOUR_TOKEN')
vk = vk_session.get_api()
user_info = vk.users.get(user_ids='username', fields='id')
print(user_info[0]['id'])
```

## Безопасность

### Рекомендации по безопасности:
1. Добавляйте только доверенных пользователей в качестве администраторов
2. Регулярно проверяйте список администраторов
3. Удаляйте права у неактивных администраторов
4. Используйте сложные токены VK API
5. Ограничивайте доступ к файлам конфигурации

### Мониторинг активности:
- Все действия администраторов логируются
- Уведомления отправляются только активным администраторам
- История команд сохраняется в базе данных

## Устранение неполадок

### Проблема: "Ошибка VK API при получении информации о пользователе"
**Решение:** Проверьте правильность VK ID и доступность профиля

### Проблема: "Пользователь не найден в базе данных"
**Решение:** Убедитесь, что пользователь существует в ВКонтакте и ID указан правильно

### Проблема: "Ошибка при добавлении администратора"
**Решение:** Проверьте права доступа к базе данных и корректность токена VK API

## Поддержка

При возникновении проблем:
1. Проверьте логи в файле `logs/bot.log`
2. Убедитесь в корректности настроек в `config/config.py`
3. Проверьте доступность VK API
4. Обратитесь к документации по VK API
